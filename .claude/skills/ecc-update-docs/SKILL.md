# ecc-update-docs

Read code, scripts and existing documentation, then update only affected sections. Verify commands, paths, environment variable names and API examples against actual implementation. Describe required versus optional configuration and omit secret values.
Keep documentation concise; prefer existing docs over creating redundant files. Do not invent metrics, links, deployment state, or screenshots. Report changes and any examples that could not be exercised.
